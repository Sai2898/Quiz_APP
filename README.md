# 🧠 Quiz App

An interactive and responsive **Quiz Application** built with **HTML, CSS, and JavaScript**. The application allows users to answer multiple-choice questions, navigate between questions, view their final score, and review the correct answers after completing the quiz.


---

## 🎯 How to Use

1. Open the Quiz App.
2. Read the displayed question.
3. Select the correct option.
4. Click **Next** to continue.
5. Use **Previous** to revisit questions.
6. Complete the quiz.
7. View your final score.
8. Click **Show Answers** to review the correct answers.
9. Click **Reload** to start again.
